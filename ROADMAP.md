# Development roadmap

Drop Ads is a Firefox + Chromium Manifest V3 privacy-first browser-local blocker. `ROADMAP.md` is the sole authority for canonical milestone numbering; completed tranche narratives live under `docs/MILESTONES_*.md` and focused qualification guides live under `docs/`.

## Product invariants

- Firefox and Chromium share one reviewed source tree wherever practical.
- Normal operation requires no owned Drop Ads server.
- **Zero telemetry, analytics, browsing/request history, matched-element history, page/DOM snapshots, retained blocked-request/contribution statistics, timestamps, or user/device identifiers.**
- Network precedence: **personal allow > personal block > shared allow > shared block**.
- Cosmetic precedence: **personal allow > personal hide > shared allow > shared hide**.
- Personal/site/session recovery controls remain available under large shared policy.
- Remote lists are hostile declarative data: bounded download/work, strict UTF-8, public-source admission, validation, transactional activation, source-bound cache, and last-known-good fallback.
- Remote executable code is forbidden. Basic declarative cosmetics are supported; procedural/scriptlet/executable syntax remains unsupported pending a separate threat model.
- Builds/packages fail closed on permissions, runtime graph, source structure/text, generated contents, package provenance, and archive verification.
- No feature silently truncates user or remote policy into different semantics merely to fit a limit.
- Community contribution remains optional and user-reviewed: no Drop Ads backend, no embedded GitHub token, and exact URLs reduce to a canonical public domain before any GitHub handoff.
