Local-first browser blocking. No telemetry, analytics, request history, browsing-history collection, or usage statistics.

Personal blocklist

Add a domain such as ads.example.com or an exact HTTP(S) URL. Community submission is always separate from local blocking.

    Personal allowlist

    Your allow rules outrank personal and shared block rules, including country-code TLD blocks.

      Country / region TLD blocking

      Block navigation or all requests to selected country-code TLDs. This is suffix policy, not GeoIP: a TLD does not prove where a server or company is physically located. Personal allows, site disable, and session pause still outrank/recover from these blocks.

        Cosmetic filtering

        Hide page elements with local CSS selectors. Leave Site blank for a global personal rule, or scope it to one domain. These rules stay local and do not record which page elements you viewed.

            Disabled sites

            Sites disabled from the toolbar appear here. Re-enable filtering at any time.

              Filter lists

              Drop Ads ships a packaged community baseline and can update it from GitHub when reachable. Adblock-style lists may contribute validated network rules and basic declarative cosmetic selectors. Add other HTTPS network-filter or hosts lists directly; no Drop Ads server is involved.

              Enable, disable, add, and remove operations are activated transactionally. If a new policy cannot be accepted, the previous configured/active policy remains in place.

                Cookie protection

                Third-party protection is the default. Hard mode removes cookie headers on all HTTP(S) resource types and will break sites that require logins or sessions.

                  Backup and restore

                  Export a local JSON backup of your configured network/cosmetic rules, country TLD rules, persistent exceptions, cookie preferences, and filter subscriptions. Backups exclude filter cache, temporary session pauses, request/browsing data, page contents, statistics, identifiers, and timestamps.

                  Importing is an explicit local action. Enabled external filter-list URLs in the backup may be contacted afterward by the normal list refresh path.

                  Community contribution

                  Off by default. When enabled, Drop Ads opens a prefilled GitHub issue for review; it never embeds a GitHub token or silently posts on your behalf. Exact URLs are reduced to their domain before leaving the browser. Country TLD policy and cosmetic selectors are not valid community submissions.
